📡 Sensor Requirements in Robots

Sensor selection, specifications, interfacing — Tilt, Proximity, Temperature, DHT11, IR, Ultrasonic, Bluetooth, GPS, GSM.

📌 What is a Sensor?

Sensor: A device that detects or measures a physical quantity (light, temperature, distance, touch, etc.) and converts it into an electrical signal that a controller can process.
Active Sensor: Requires an external power source to operate and emits energy to detect the environment. Example: Ultrasonic sensor, IR sensor (emits IR light).
Passive Sensor: Does not emit energy; only detects naturally occurring signals. Example: LDR (detects ambient light), thermistor (detects heat).
Tactile Sensor: Detects physical contact or touch. Examples: Force sensors, pressure sensors, touch pads. Used in robot grippers.
Non-Tactile Sensor: Detects without physical contact (proximity-based). Examples: IR, Ultrasonic, Camera, Radar.

🌡️ Individual Sensor Explanations

Note  DHT11 – Temperature & Humidity Sensor

DHT11 is a basic, low-cost digital sensor that measures both temperature and humidity.

Specifications:

  • Temperature range: 0°C to 50°C (±2°C accuracy)
  • Humidity range: 20% to 90% RH (±5% accuracy)
  • Operating voltage: 3.3V – 5V DC
  • Output: Digital single-wire protocol
  • Sampling rate: 1 reading per second

Working Principle:

  1. A capacitive humidity sensor measures moisture — humidity changes the capacitance of the sensor material.
  2. A thermistor (NTC type) measures temperature — resistance decreases as temperature increases.
  3. An internal 8-bit microcontroller converts these readings to digital values.
  4. Data is sent as a 40-bit signal via a single data line to the Arduino/controller.

Pinout: VCC (power), DATA (signal), GND (ground). A 10kΩ pull-up resistor is used on the data line.

Applications: Weather stations, HVAC systems, greenhouse automation, home automation.

💡 vs DHT22: DHT22 has better accuracy (±0.5°C) and wider range but is more expensive. DHT11 is suitable for basic applications.
Note  IR Sensor – Infrared Sensor

An IR (Infrared) Sensor detects objects or measures distance using infrared light. It has an IR emitter (LED) and an IR receiver (photodiode).

Working Principle:

  1. IR LED emits infrared radiation (invisible to human eye).
  2. When an object comes in range, it reflects the IR light back.
  3. The photodiode detects the reflected IR signal.
  4. Output goes LOW (0) when object detected, HIGH (1) when no object.

Types:

  • Reflective IR: Emitter and receiver on same side — detects nearby objects
  • Through-beam IR: Emitter and receiver face each other — object detection on crossing

Specifications: Range: 2–30cm. Operating voltage: 5V. Output: Digital (High/Low).

Applications: Line-following robots, obstacle avoidance, TV remotes, counting objects on conveyors.

Note  Ultrasonic Sensor (HC-SR04)

The HC-SR04 Ultrasonic Sensor measures distance by emitting ultrasonic sound waves and measuring the time for the echo to return.

Working Principle:

  1. A 10µs HIGH pulse is sent to the TRIG pin.
  2. Sensor emits 8 pulses of 40kHz ultrasonic sound.
  3. Sound waves travel, hit an object, and bounce back.
  4. The ECHO pin goes HIGH for the duration the sound traveled.
  5. Distance = (Time × Speed of Sound) / 2 = (Time × 343 m/s) / 2

Specifications: Range: 2cm–400cm, Accuracy: ±3mm, Operating voltage: 5V, Frequency: 40kHz.

Pins: VCC, TRIG (trigger input), ECHO (echo output), GND.

Applications: Obstacle avoidance, parking sensors, water level detection, robot navigation.

💡 Formula: Distance (cm) = (Echo pulse time in µs) / 58
Note  Tilt Sensor

A Tilt Sensor (also called inclination sensor) detects the orientation or tilt of a device with respect to gravity.

Working Principle (Ball-type tilt sensor):

  1. Inside the sensor is a small metallic ball and two contact pins.
  2. When the sensor is upright, the ball rests on the contacts → circuit is CLOSED → output HIGH.
  3. When tilted, the ball rolls away from contacts → circuit OPEN → output LOW.

Types:

  • Mercury tilt switch: Uses liquid mercury (obsolete, toxic)
  • Ball tilt switch: Metal ball inside cylinder (common, safe)
  • MEMS accelerometer: Modern digital tilt sensing (MPU-6050)

Specifications: Operating voltage: 3.3V–5V. Output: Digital (HIGH/LOW). Tilt angle threshold: typically 30°–45°.

Applications: Anti-theft alarms, phone screen rotation, drone stabilization, fall detection systems.

Note  Proximity Sensor

A Proximity Sensor detects the presence of nearby objects without physical contact. It emits an electromagnetic field or beam and detects changes caused by a nearby object.

Types of Proximity Sensors:

  • Inductive: Detects metal objects using electromagnetic induction. Used in CNC machines.
  • Capacitive: Detects any material (including non-metal) by measuring capacitance change. Used for liquid level detection.
  • Ultrasonic Proximity: Uses sound waves; works on any material. Used in parking systems.
  • IR Proximity: Uses infrared light reflection. Used in smartphones (screen off during calls).
  • Magnetic (Reed Switch): Detects magnets/magnetic fields.

Applications: Conveyor belt object detection, robot arm safety stop, automatic doors, touchless switches.

Note  LDR – Light Dependent Resistor

An LDR (Light Dependent Resistor) is a passive sensor whose resistance changes depending on the amount of light falling on it.

Working Principle:

  • In darkness: high resistance (1MΩ or more)
  • In bright light: low resistance (~100Ω)
  • Made of semiconductor material (cadmium sulfide) — photons free electrons, reducing resistance.

Connection: Used as part of a voltage divider circuit. Voltage across LDR changes with light → read by Arduino analog pin.

Applications: Automatic street lights, light-following robots, camera exposure control, burglar alarms.

📶 Wireless Communication Modules

Note  Bluetooth Module (HC-05 / HC-06)

The HC-05/HC-06 is a Bluetooth serial communication module used for wireless data transfer between a robot and a smartphone or PC.

  • Range: ~10 meters
  • Frequency: 2.4GHz ISM band
  • Communication: UART serial (TX/RX pins)
  • HC-05: Can work as Master or Slave
  • HC-06: Only Slave mode
  • Baud rate: Default 9600 bps

Applications: Bluetooth-controlled robots, wireless sensor data logging, phone-to-Arduino communication.

Note  ESP8266 – WiFi Module

The ESP8266 is a low-cost WiFi microcontroller module that allows devices to connect to the internet (IoT applications).

  • Processor: 80MHz Tensilica L106 32-bit RISC
  • WiFi: IEEE 802.11 b/g/n (2.4GHz)
  • Operating Voltage: 3.3V
  • GPIO Pins: Multiple digital I/O pins
  • Flash Memory: 512KB to 4MB
  • Programmable using Arduino IDE

Modes: Station (connects to WiFi), Access Point (creates WiFi hotspot), or Both.

Applications: IoT robots, cloud-connected sensors, web-controlled robots, smart home devices.

💡 Note: ESP8266 can act as a standalone controller — no need for a separate Arduino in many projects.
Note  GPS Module (NEO-6M)

A GPS (Global Positioning System) Module receives signals from satellites to determine the precise location (latitude, longitude, altitude) of a robot.

  • Module: NEO-6M (common Arduino-compatible GPS)
  • Accuracy: ~2.5 meters
  • Interface: UART (TX/RX)
  • Output: NMEA sentences (text strings containing location data)
  • Channels: 50 satellite channels
  • Update rate: 1Hz (1 reading/second)

Applications: Autonomous outdoor robots, drone navigation, vehicle tracking, search-and-rescue robots.

Note  GSM Module (SIM800L / SIM900)

A GSM (Global System for Mobile communication) Module allows a robot to send/receive SMS messages and make phone calls using a SIM card and mobile network.

  • Module: SIM800L or SIM900
  • Bands: 850/900/1800/1900 MHz (quad-band)
  • Interface: UART (AT commands)
  • Features: SMS, voice call, GPRS data
  • Operating voltage: 3.4V–4.4V

AT Commands used: AT (test), AT+CMGF=1 (SMS text mode), AT+CMGS (send SMS).

Applications: Remote robot alerts via SMS, IoT alarm systems, security robots, remote monitoring.

💡 Difference: GPS = finds location using satellites. GSM = communicates using cellular network. They are often combined in tracking systems.

❓ Short & Long Questions

Short  What is a Tactile Sensor?

A Tactile Sensor is a sensor that detects physical contact, pressure, or force. It works like the human sense of touch. It is used in robot grippers to detect when an object is held and how firmly. Examples: Force-sensitive resistor (FSR), piezoelectric sensor, capacitive touch pad. Applications: Robot grippers, prosthetic hands, touchscreens, surgical robots.

Short  What is the role of Closed Loop Control System in robotics?

In robotics, a closed loop control system uses sensor feedback to continuously correct the robot's actions. The sensor (e.g., encoder, camera) measures the actual output and compares it with the desired value. The error is used to adjust the actuator. This ensures precise positioning, consistent speed, and accurate force control — essential for tasks like welding, surgery, and assembly.

Short  What is a temperature sensor? Give two examples.

A temperature sensor measures the degree of heat or coldness of an environment and converts it to an electrical signal. Examples: (1) DHT11 – measures temperature and humidity digitally. (2) LM35 – analog sensor; outputs 10mV per °C. Other examples: DS18B20 (digital, waterproof), NTC Thermistor (analog resistance change), thermocouple (high-temperature range).

Long  Explain the concept of sensors in robotic systems.

Sensors are the "eyes and ears" of a robot — they allow it to perceive and interact with the environment.

Classification of Sensors in Robotics:

  • Proprioceptive Sensors: Measure internal state of robot — encoders (position), gyroscopes (orientation), current sensors.
  • Exteroceptive Sensors: Measure external environment — cameras, ultrasonic, IR, GPS.
  • Active Sensors: Emit energy and detect its return (Ultrasonic, IR, Radar).
  • Passive Sensors: Only receive signals (Camera, microphone, thermistor).

Role of Sensors:

  1. Perception: Detect obstacles, measure distance, identify objects.
  2. Feedback: Provide data for closed-loop control.
  3. Safety: Stop robot when unexpected contact occurs.
  4. Navigation: GPS + IMU for autonomous movement.
  5. Manipulation: Force/tactile sensors for precise gripping.

Sensor interfacing to controllers: Sensors connect via Analog pins (ADC conversion), Digital pins (HIGH/LOW), or communication protocols (I2C, SPI, UART) to Arduino, Raspberry Pi, or 8051.

💡 Key Point: Without sensors, a robot is blind — it cannot adapt to changes in the environment and becomes just a fixed automation machine.

Long  Describe the working principle of an ultrasonic sensor.

The HC-SR04 Ultrasonic Sensor works on the principle of SONAR (Sound Navigation And Ranging).

Step-by-step Working:

  1. The microcontroller sends a 10µs HIGH pulse to the TRIG pin.
  2. This triggers the sensor to emit 8 ultrasonic pulses at 40kHz frequency.
  3. The ultrasonic waves travel through air at 343 m/s.
  4. When the waves hit an obstacle, they reflect back as echo.
  5. The ECHO pin goes HIGH for the duration = time taken for sound to travel to object and return.
  6. Distance = (Time × 343) / 2 meters

Arduino Code Formula:

duration = pulseIn(ECHO, HIGH);
distance = duration * 0.034 / 2; // in cm

Limitations: Cannot detect soft/sound-absorbing objects well. Works poorly at very small angles. Affected by temperature changes (speed of sound changes).

🎯 Module 2 – Key Points for Exam

  • Active sensor = emits energy (IR, Ultrasonic); Passive sensor = only receives (LDR, thermistor)
  • Tactile = requires contact; Non-tactile = no contact needed
  • DHT11 measures BOTH temperature (0–50°C) and humidity (20–90%) via single data wire
  • Ultrasonic: TRIG input → 8 pulses → ECHO output; Distance = time × 0.034 / 2
  • Tilt sensor uses ball-in-cylinder mechanism; modern ones use MEMS accelerometers
  • HC-05 = Master/Slave Bluetooth; HC-06 = Slave only
  • ESP8266 = WiFi + microcontroller in one chip; 3.3V, uses AT commands or Arduino IDE
  • GPS = location from satellites (NEO-6M, NMEA output)
  • GSM = cellular communication — SMS and calls (SIM800L, AT commands)
  • Sensor interfacing: Analog → ADC, Digital → GPIO, Serial → UART/I2C/SPI
