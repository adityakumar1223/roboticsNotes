💻 Controllers & Output Port Handling

8051 microcontroller, Arduino, Raspberry Pi — architecture, pin configuration, and comparison.

📌 Key Definitions

Microprocessor: A CPU on a single chip that performs arithmetic, logic, and control operations. It requires external RAM, ROM, and I/O ports to function. Example: Intel 8085, Intel Core i7.
Microcontroller: A complete computer on a single chip — contains CPU, RAM, ROM (Flash), I/O ports, timers, ADC, and communication interfaces. Example: 8051, ATmega328P (Arduino), PIC.
Instruction: A binary command that tells the microcontroller/processor to perform a specific operation (e.g., load data, add numbers, jump to address). Each instruction has an opcode and operand.
ALE (Address Latch Enable): A control signal in the 8051 used to demultiplex the lower byte of the address bus (AD0–AD7) from the data bus. It goes HIGH when address is on the bus and LOW when data is on the bus.
Port Handling: The process of reading from or writing to the I/O ports of a microcontroller to interact with external devices (LEDs, motors, sensors).

🔧 8051 Microcontroller – Architecture

💡 Also called 8951 in some syllabi. MCS-51 family by Intel. The AT89C51 is a popular CMOS version by Atmel.
Fig: 8051 Microcontroller Internal Architecture

Key Features of 8051:

  • 8-bit CPU (operates on 8 bits at a time)
  • 4KB on-chip ROM (program memory)
  • 128 bytes on-chip RAM (data memory)
  • Four 8-bit I/O ports: P0, P1, P2, P3 (32 I/O pins total)
  • Two 16-bit timers/counters: Timer 0 and Timer 1
  • Full-duplex UART serial port
  • 5 interrupt sources (2 external, 2 timer, 1 serial)
  • Operating frequency: up to 12 MHz
  • Harvard architecture (separate program and data memory)
💡 ALE Pin: Address Latch Enable — multiplexes P0 as either address bus (A0–A7) or data bus (D0–D7). Goes HIGH when address is valid.

🔵 Arduino – Concept & Features

Arduino: An open-source electronics platform based on easy-to-use hardware and software. It consists of a microcontroller (ATmega328P in Arduino UNO) and the Arduino IDE for programming in a simplified C/C++ language.

Arduino UNO Specifications:

  • Microcontroller: ATmega328P
  • Operating Voltage: 5V
  • Digital I/O Pins: 14 (6 PWM)
  • Analog Input Pins: 6 (10-bit ADC)
  • Flash Memory: 32KB
  • SRAM: 2KB, EEPROM: 1KB
  • Clock Speed: 16 MHz
  • USB interface for programming
  • Power: USB / 7–12V barrel jack

Arduino IDE Steps:

  1. Install Arduino IDE software
  2. Select Board (Tools → Board → Arduino UNO)
  3. Select Port (Tools → Port → COM X)
  4. Write code in setup() and loop()
  5. Compile (Verify button ✓)
  6. Upload (→ button) to board
  7. Monitor output using Serial Monitor

Example: Blink LED (Basic Arduino Program)

void setup() {
  pinMode(13, OUTPUT);   // Set pin 13 as output
}

void loop() {
  digitalWrite(13, HIGH); // LED ON
  delay(1000);             // Wait 1 second
  digitalWrite(13, LOW);  // LED OFF
  delay(1000);             // Wait 1 second
}
💡 ATmega328P is an 8-bit AVR RISC microcontroller. It has 131 instructions, most executing in a single clock cycle. It is used in Arduino UNO, Nano, and Mini boards.

🍓 Raspberry Pi – Concept & Features

✅ When to Use Which?

  • Use Arduino for: simple motor control, sensor reading, real-time tasks (needs precise timing)
  • Use Raspberry Pi for: image processing, ROS, web server, AI, complex logic
  • Use Both together: Pi for high-level processing, Arduino for real-time low-level control

❓ Short & Long Questions

Short  What is a Microprocessor?

A microprocessor is a programmable digital device that contains the functions of a CPU on a single integrated circuit. It executes instructions stored in external memory by performing arithmetic, logical, and control operations. It requires external components (RAM, ROM, I/O) to build a complete system. Example: Intel 8085, 8086, Core i5, AMD Ryzen.

Short  What is the use of ALE signal?

ALE (Address Latch Enable) is a control signal in the 8051 used to demultiplex Port 0. Since Port 0 serves dual purpose (lower address byte AND data bus), ALE signal indicates when Port 0 is carrying an address (ALE = HIGH) vs data (ALE = LOW). An external latch (like 74LS373) captures the address when ALE goes HIGH, freeing P0 for data transfer.

Short  What are the interrupts available in 8051?

The 8051 has 5 interrupt sources:

  • INT0: External Interrupt 0 (pin P3.2)
  • INT1: External Interrupt 1 (pin P3.3)
  • Timer 0 (TF0): Timer 0 overflow interrupt
  • Timer 1 (TF1): Timer 1 overflow interrupt
  • Serial (RI/TI): Serial port receive/transmit interrupt

Interrupt Enable (IE) register controls which interrupts are active. EA bit (IE.7) is the global interrupt enable.

Long  Explain the architecture of 8051 microcontroller.

The 8051 is an 8-bit microcontroller designed by Intel in 1981. It follows Harvard architecture (separate program and data memory).

Key architectural components:

  • CPU: 8-bit ALU + Control Unit. Executes instructions from ROM.
  • Program Memory (ROM): 4KB internal Flash for storing the program code. Can be expanded to 64KB externally.
  • Data Memory (RAM): 128 bytes internal. Lower 32 bytes = 4 register banks (R0–R7). Bytes 20H–2FH = bit-addressable area.
  • I/O Ports: P0 (8-bit, open drain, address/data), P1 (8-bit, general I/O), P2 (8-bit, high-byte address), P3 (8-bit, special functions: INT, RXD, TXD, etc.).
  • Timers: Two 16-bit timers (T0, T1) for delay, counting, baud rate generation.
  • Serial Port: Full-duplex UART using P3.0 (RXD) and P3.1 (TXD).
  • Interrupt Controller: 5 interrupt sources with 2-level priority.
  • Oscillator: Internal oscillator driven by crystal (typically 11.0592 MHz or 12 MHz).
  • SFRs: Special Function Registers (ACC, B, PSW, SP, DPTR, TCON, TMOD, SCON, IE, IP).
💡 Machine Cycle: The 8051 takes 12 oscillator clock cycles to complete 1 machine cycle. At 12MHz, each machine cycle = 1µs.
Long  Explain about Raspberry Pi.

Raspberry Pi is a series of small single-board computers developed by the Raspberry Pi Foundation (UK) to promote computer science education.

Hardware (Raspberry Pi 4 Model B):

  • Processor: Broadcom BCM2711, quad-core ARM Cortex-A72 @ 1.5GHz
  • RAM: 2GB, 4GB, or 8GB LPDDR4
  • Storage: MicroSD slot
  • Ports: 2× USB 3.0, 2× USB 2.0, 2× micro-HDMI, 40-pin GPIO header
  • Connectivity: Gigabit Ethernet, WiFi (2.4GHz + 5GHz), Bluetooth 5.0
  • Power: 5V/3A via USB-C

Software: Runs Raspberry Pi OS (Debian-based Linux). Supports Python, C/C++, Java, Scratch. Compatible with ROS (Robot Operating System).

GPIO Pins: 40-pin header — includes 3.3V, 5V power, GND, I2C, SPI, UART, PWM pins. Used to interface sensors, motors, and displays.

Applications in Robotics: ROS-based robot control, computer vision (OpenCV), machine learning (TensorFlow Lite), web-based robot interface, IoT gateway.

Long  Write the steps to execute a program using Arduino IDE with an example.

Steps to execute a program in Arduino IDE:

  1. Install Arduino IDE from arduino.cc (available for Windows/Mac/Linux)
  2. Connect Arduino UNO to PC via USB cable
  3. Select Board: Tools → Board → Arduino UNO
  4. Select Port: Tools → Port → COM3 (or relevant port)
  5. Write the program in the IDE editor:

Example: Blink LED on Pin 13

// setup() runs once on power-up
void setup() {
  pinMode(13, OUTPUT); // Set pin 13 as output
}

// loop() runs repeatedly
void loop() {
  digitalWrite(13, HIGH); // Turn LED ON
  delay(1000);             // Wait 1000ms (1 second)
  digitalWrite(13, LOW);  // Turn LED OFF
  delay(1000);             // Wait 1 second
}
  1. Verify (Compile): Click the ✓ (tick) button — checks for syntax errors
  2. Upload: Click → (arrow) button — uploads hex file to Arduino
  3. Observe: LED on pin 13 blinks every second
  4. Debug: Use Serial Monitor (Ctrl+Shift+M) to view serial output

🎯 Module 3 – Key Points for Exam

  • Microprocessor = CPU only; Microcontroller = CPU + RAM + ROM + I/O on one chip
  • 8051 has 4KB ROM, 128B RAM, 4 ports (P0–P3), 2 timers, 5 interrupts
  • ALE = Address Latch Enable — demultiplexes P0 as address/data bus
  • 8051 Interrupts: INT0, INT1, Timer0, Timer1, Serial (5 total)
  • Arduino UNO uses ATmega328P @ 16MHz, 14 digital I/O, 6 analog pins
  • Arduino IDE: setup() runs once; loop() runs repeatedly
  • Raspberry Pi is a full single-board computer running Linux OS
  • Arduino = best for real-time control; Raspberry Pi = best for complex processing
  • GPIO on Raspberry Pi = 40 pins (digital only, 3.3V logic)
  • Both can be used together: Pi for high-level, Arduino for real-time tasks
