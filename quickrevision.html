⚡ Quick Revision – All Modules

Key definitions, formulas, differences, and must-remember points for all 5 modules.

🤖 Module 1 – Robotic Automation

Core Definitions

  • Robotics = Mech + Electrical + CS combined
  • Automation = tasks done without human help
  • DOF = number of independent movements
  • 6 DOF = full 3D position + orientation
  • Manipulator = arm with links + joints

Asimov's 3 Laws

  • 1st: Robot cannot harm humans
  • 2nd: Must obey humans (if no conflict)
  • 3rd: Protect itself (if no conflict)
  • Priority: Safety > Obedience > Self

Control Systems

  • Open loop = No feedback (simple, less accurate)
  • Closed loop = Uses feedback (accurate)
  • Servo = closed loop with encoder feedback
  • Non-servo = open loop, fixed path
  • Thermostat = closed loop example

Joints & Links

  • Revolute (R) = rotational, 1 DOF
  • Prismatic (P) = linear/sliding, 1 DOF
  • Spherical = 3D rotation, 3 DOF
  • Pitch = up/down tilt
  • Yaw = left/right rotation
  • Roll = sideways tilt

Automation Types

  • Fixed = one task, high volume, less flexible
  • Programmable = reprogrammable, batch
  • Flexible = real-time adaptation
  • Fixed examples: assembly lines, bottling
  • Programmable examples: CNC, robots

Key Formulas

  • Torque = Force × Distance (Nm)
  • Power = Torque × Angular velocity (W)
  • Good control: Accurate, Stable, Fast, Sensitive
  • Actuator types: Electric, Pneumatic, Hydraulic

📡 Module 2 – Sensors

Sensor Types

  • Active = emits energy (IR, Ultrasonic)
  • Passive = only receives (LDR, thermistor)
  • Tactile = needs contact (force sensor)
  • Non-Tactile = no contact (IR, camera)
  • Proprioceptive = internal state (encoder)
  • Exteroceptive = external (camera, GPS)

DHT11 Sensor

  • Measures: Temperature + Humidity
  • Temp range: 0°C to 50°C (±2°C)
  • Humidity: 20% to 90% RH
  • Output: Digital (single-wire)
  • Voltage: 3.3V–5V
  • Uses capacitive + thermistor principle

Ultrasonic (HC-SR04)

  • Principle: SONAR (sound reflection)
  • Frequency: 40kHz
  • Range: 2cm – 400cm
  • Pins: VCC, TRIG, ECHO, GND
  • Distance = time × 0.034 / 2 cm

Wireless Modules

  • HC-05: Bluetooth, Master+Slave, ~10m
  • HC-06: Bluetooth, Slave only
  • ESP8266: WiFi + MCU, 3.3V, IoT
  • NEO-6M: GPS, NMEA output, ~2.5m accuracy
  • SIM800L: GSM, SMS + calls, AT commands

IR Sensor Working

  • IR LED emits → object reflects → photodiode detects
  • Output LOW = object detected
  • Range: 2–30cm typically
  • Used in: line following, obstacle avoidance

Tilt Sensor

  • Detects orientation vs gravity
  • Ball-type: metal ball on contacts
  • Upright = circuit closed (HIGH)
  • Tilted = circuit open (LOW)
  • Modern: MEMS accelerometer (MPU-6050)

💻 Module 3 – Controllers

8051 Key Facts

  • 8-bit microcontroller by Intel
  • 4KB ROM, 128 bytes RAM
  • 4 I/O ports: P0, P1, P2, P3
  • 2 Timers: T0, T1 (16-bit)
  • 5 interrupts: INT0, INT1, T0, T1, Serial
  • Harvard architecture

8051 Ports

  • P0: Address/Data bus (dual purpose)
  • P1: General I/O (only pure I/O port)
  • P2: High-byte address bus
  • P3: Special functions (INT, UART, T0, T1)
  • ALE: Separates address from data on P0

Arduino UNO

  • MCU: ATmega328P @ 16MHz
  • Digital pins: 14 (6 PWM)
  • Analog pins: 6 (10-bit ADC)
  • Flash: 32KB, RAM: 2KB
  • Voltage: 5V operating
  • setup() once + loop() forever

Raspberry Pi vs Arduino

  • RPi = Single-board Computer (Linux OS)
  • Arduino = Microcontroller (no OS)
  • RPi: 1.5GHz, 2–8GB RAM
  • Arduino: 16MHz, 2KB RAM
  • RPi: Complex AI, ROS, vision
  • Arduino: Real-time sensor/motor control

Microprocessor vs Microcontroller

  • µP: CPU only, needs external RAM/ROM
  • µC: CPU + RAM + ROM + I/O on one chip
  • µP: High processing, high power
  • µC: Low power, embedded use
  • µP example: Intel Core, 8085
  • µC example: 8051, ATmega328

Arduino IDE Steps

  • Install IDE → Connect board → USB
  • Tools → Board → Arduino UNO
  • Tools → Port → COM X
  • Write setup() + loop() code
  • Verify (✓) → Upload (→)
  • Serial Monitor for debugging

⚙️ Module 4 – Sequential Control & Vision

Sequential Control

  • Fixed order step-by-step execution
  • One step completes before next starts
  • Steps: Define tasks → I/O → Flowchart → Code → Test
  • Example: Pick → Move → Place → Return

Image Processing Steps

  • 1. Acquisition (capture via camera)
  • 2. Preprocessing (noise removal, resize)
  • 3. Segmentation (separate objects)
  • 4. Feature extraction (edges, shapes)
  • 5. Recognition (classify/detect)

Vision Types

  • Image Processing = operations on images
  • Machine Vision = industrial inspection
  • Computer Vision = AI visual understanding
  • Robot Vision = guides robot actions

Machine Learning

  • Supervised: labeled data, classification
  • Unsupervised: unlabeled, clustering
  • Reinforcement: rewards/penalties
  • Overfitting: fix with dropout, more data

CNN Layers

  • Input → Convolutional → ReLU activation
  • Pooling → Fully Connected → Output
  • Used for image classification, detection
  • Examples: LeNet, VGG, ResNet, YOLO
  • Pixel = smallest image unit (0–255)

Canny Edge Detection

  • 1. Gaussian blur (noise reduction)
  • 2. Compute image gradient (Sobel)
  • 3. Non-maximum suppression
  • 4. Double threshold (strong/weak edges)
  • 5. Hysteresis edge tracking

🖥️ Module 5 – ROS & Gazebo

ROS Basics

  • ROS = middleware, not a real OS
  • Runs on Ubuntu Linux
  • roscore = start Master first always
  • Nodes = individual programs
  • catkin_make = build workspace

Topics vs Services

  • Topic = async, publish/subscribe
  • Service = sync, request/response
  • Topic → streaming continuous data
  • Service → one-time command
  • Messages (.msg) / Services (.srv)

Common ROS Topics

  • /cmd_vel → velocity commands (Twist)
  • /odom → odometry (position)
  • /scan → LIDAR data
  • /camera/image_raw → camera frames
  • /tf → coordinate transforms

Gazebo Features

  • Physics engine: ODE (gravity, friction)
  • Sensor simulation (camera, LIDAR, IMU)
  • 3D world building (SDF format)
  • ROS bridge via gazebo_ros package
  • TurtleBot3 = common simulation robot

Key ROS Commands

  • roscore → start master
  • rosrun pkg node → run a node
  • rosnode list → show all nodes
  • rostopic list → show all topics
  • rostopic echo /topic → print data
  • rqt_graph → visualize node network

ROS Tools

  • RViz = 3D visualization of sensors/robot
  • Gazebo = physics simulation
  • rqt = GUI toolkit for ROS
  • roslaunch = start multiple nodes
  • rosbag = record/play topic data
  • roswtf = diagnose ROS issues
